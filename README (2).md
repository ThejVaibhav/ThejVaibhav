# 🚀 Featured Projects

### 🧠 IT HelpDesk AI Agent — Centific Premier Hackathon 2.0
> Built an AI-powered IT HelpDesk agent with a 3-layer architecture: LLM reasoning core, Azure TTS avatar, and a virtual assistant joining Microsoft Teams as a live participant.
- Confidence-based escalation to human agents, role-based access control (6 roles), JWT auth, and audit logs
- Admin panel for knowledge management, escalation queues, and custom tool creation without code
- **Stack:** FastAPI · React 18 · PostgreSQL · Claude Sonnet · Azure TTS · MS Teams Bot SDK · Docker

### 🕸️ GraphRAG System for Multi-Hop Reasoning
> Answers complex questions requiring multi-hop reasoning by combining knowledge graphs and vector search.
- Used spaCy for entity extraction and Gemini API to construct structured knowledge graphs
- Evaluated with F1, Exact Match, and LLM-based faithfulness metrics
- **Stack:** Python · Neo4j · ChromaDB · spaCy · Gemini API · FastAPI · Docker · Streamlit

### 🔍 Online Fraud Detection — ML Classification
> Trained a model on a heavily imbalanced dataset (0.17% fraud) achieving AUC-ROC of 0.98 and F1 of 0.94.
- Used SMOTE + XGBoost; engineered transaction velocity features to detect suspicious patterns
- Applied SHAP explainability for business-interpretable fraud insights
- **Stack:** Python · Scikit-learn · XGBoost · SHAP · Pandas · NumPy · Matplotlib · Seaborn
